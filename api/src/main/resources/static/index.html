Agent Society Lab

About

The question. When each agent can see how earlier agents rated the tickets, does the line end up less accurate than agents working alone? Does it recover if the first agents are wrong, and does a stronger model placed early or late change what a weaker model does? The tickets have a known truth: twelve are serious and twelve are routine.

The design. A world is 200 agents acting in order. Each picks four tickets and rates each HIGH or LOW in one call. In the influence conditions it also sees, for every ticket, how many earlier agents rated it HIGH. Eight worlds per cell share their persona and ticket-order seeds across conditions. The method follows Hashemi et al. (arXiv 2610.30769, preprint). A Python LangGraph engine plays the worlds, a Spring Boot API stores every event and raw model call, and this page replays them.

The limits. These are tendencies of language models in a toy queue, not evidence about people or about any production system. Sampling uses provider defaults, so reruns differ, and eight worlds per cell can only detect large differences.
