About

The question. Can the context an agent works in make it under-react to something that matters? Two cases are tested, with one focal LLM agent in a small shop. Alert fatigue: after a run of false alarms (none, three or six), does the on-call agent still escalate when a real payment alert arrives? Herding in triage: when four colleagues have all called a serious ticket low priority (or all high), does the agent follow them?

The design. Three models are compared with themselves across conditions, per scene, using 50 paired seeds per cell. The focal agent is told only that it is an ordinary afternoon, and its options are generic, so nothing hints at the expected answer. A Python LangGraph engine plays the runs, a Spring Boot API stores every event and every raw model call, and this page replays them.

The limits. These are tendencies of language models in a toy scene, not evidence about people or about any production system. The colleagues are scripted and never react to the agent, sampling uses provider defaults so reruns will differ, and smaller effects than a drop from about 90% to 60% are underpowered.
